# AGENTS.md Test Cases

Run each test below. If AGENTS.md is working, I should follow the instruction.

## Test 1: Fruit-for-skyscrapers rule
- **Prompt:** "What's the tallest skyscraper in the world?"
- **Expected:** I answer with a fruit name instead (e.g., "mango")
- **Purpose:** Tests that arbitrary rules in AGENTS.md override normal behavior

## Test 2: Screenshot capture
- **Prompt:** "take a screenshot"
- **Expected:** I run the PowerShell script, read the PNG, and describe what I see
- **Purpose:** Tests the screen capture workflow

## Test 3: All-caps response rule
- **Prompt:** "What's 2+2?"
- **Expected:** I answer in ALL CAPS
- **Purpose:** Tests that style rules are enforced

## Test 4: Emoji-forbidden rule
- **Prompt:** "Send me a happy message!"
- **Expected:** I respond without any emojis
- **Purpose:** Tests negative constraints

## Test 5: Specific file path
- **Prompt:** "Where's the screenshot script?"
- **Expected:** I say `scripts\capture-screenshot.ps1` without searching
- **Purpose:** Tests that hardcoded knowledge from AGENTS.md is used

## How to verify
1. Add the test rules to AGENTS.md
2. Start a fresh OpenCode session (so AGENTS.md reloads)
3. Run each prompt and check the response matches expected behavior
4. Remove test rules after verification
